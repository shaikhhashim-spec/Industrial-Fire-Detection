Pipeline

This public site re-pulls live NASA FIRMS data for India and re-runs the pipeline every six hours (GitHub Actions, using a repository secret for the FIRMS key — never entered in a browser). The local app refreshes the same way on every start if its data is more than six hours old, or on demand from this page's local equivalent.
